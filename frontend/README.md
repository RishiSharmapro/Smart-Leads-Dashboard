# Frontend - Smart Leads Dashboard

## Features

- Authentication UI
- Protected Routes
- Leads Dashboard
- Filtering & Search
- Pagination
- CSV Export
- Responsive UI

## Tech Stack

- React
- TypeScript
- TailwindCSS
- Axios
- React Router DOM

## Run Locally

```bash
npm install
npm run dev
````

## Environment Variables

```env
VITE_API_URL=your_backend_url
```
